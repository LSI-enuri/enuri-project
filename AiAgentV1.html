SUMMARY
에누리서비스기획팀 · 아이데이션
에누리/다나와 AI 에이전트
아이데이션
한 줄 요약
에누리가 가진 가격 · 스펙 · 리뷰 데이터를 AI로 연결해, 사용자가 스스로 하던 정보 수집과 판단을 대신해주는 서비스
배경
사용자 니즈
일상에서 생성형 AI를 쓰듯, 상품 구매에서도 대화로 정보를 얻고 결정하고 싶다
기존 검색의 한계
키워드 검색 + 필터는 사용자가 직접 조건을 설정해야 하는 일방향 구조
에누리의 자원
멀티 쇼핑몰 가격 DB · 상세 스펙 DB · AI 리뷰 요약 — 이미 보유한 데이터
포지셔닝
네이버 · 쿠팡 에누리
상품 범위 자사 입점 상품 중심 수십 개 쇼핑몰 동시 비교
추천 중립성 자사 이익 기반 가능성 판매 이해관계 없는 중립 추천
가격 타이밍 현재가 기준 가격 추이 기반 타이밍 판단 제공
MVP 범위
1차 — PDP 구매 결정 지원
진입점 상품 상세 페이지(PDP) 내 AI 분석 버튼
파일럿 노트북 카테고리 (스펙 DB 충분 · AI 리뷰 요약 적용 중)
기존 검색과의 관계 대체가 아닌 보완. 검색·필터는 탐색 담당, AI는 구매 결정 단계 담당
추후 확대 검토
카테고리 확대 → 검색 연동(대화 결과 → 검색결과 페이지 연결) → 개인화 추천
"살만해요" 판정 기준 — 어떻게 측정하나
판정은 가격 신호 중심 + 스펙·리뷰로 보정
에누리가 객관적으로 계산할 수 있는 데이터는 가격뿐이에요. 스펙 적합성이나 리뷰 품질은 개인 상황마다 다르기 때문에 AI가 일방적으로 "좋다/나쁘다"를 판정하기 어려워요. 그래서 판정의 핵심은 가격 타이밍이고, 스펙과 리뷰는 "참고 정보"로 제공하는 구조가 현실적이에요.
판정 4단계
지금 사도 좋아요 가격 타이밍 양호
현재가가 3개월 평균 대비 일정 % 이하이고, 최근 가격이 하락 또는 안정세일 때
조건: 현재가 ≤ 3개월 평균 × 0.95 (5% 이상 저렴) + 최근 30일 최저가 근접
조금 더 기다려봐요 가격 하락 여지 있음
현재가가 3개월 평균보다 높거나, 최근 가격이 상승세일 때. 또는 출시 후 일정 기간이 안 지난 신상품일 때
조건: 현재가 > 3개월 평균 × 1.03 (3% 이상 비쌈) 또는 출시 후 60일 미만
적정 가격이에요 평균 수준
현재가가 3개월 평균 ±5% 이내이고 가격 변동이 크지 않을 때. 지금 사도 크게 손해 없음
조건: 현재가가 3개월 평균의 95~103% 범위 내
가격 확인 필요해요 데이터 부족 or 급등
가격 히스토리가 3개월 미만이거나, 최근 급격한 가격 변동이 있을 때. 신상품·품절 복귀 상품
조건: 가격 데이터 90일 미만 또는 최근 7일 내 10% 이상 급등
※ 각 판정 단계별 조건은 Claude 추천 조건 및 참고 의견입니다. 실제 서비스 적용 시 에누리 가격 DB 분석을 통해 기준값을 검증·조정해야 합니다.
스펙 요약 — 수치가 아닌 해석
에누리 스펙 DB가 하는 것
CPU 세분류 · 코어 수 · RAM 대역폭 · 무게 등 30개 이상의 항목 보유. 정형 조건 필터링의 재료.
AI가 추가로 하는 것
스펙 수치가 이 사용자에게 어떤 의미인지, 어떤 판단을 내릴 수 있는지를 해석해 전달.
스펙 DB는 "무엇인가"를 알고, AI는 "그래서 어떤가"를 말한다.
표현 방식
스펙 항목 나열은 기존 스펙 탭과 중복. AI는 "이 스펙이 나에게 어떤 의미인지"만 담당한다.
예시 — CPU
수치: Core Ultra 5 · 14코어
AI 해석: 문서·웹·영상 시청에 충분. 고사양 게임·3D 렌더링은 어려워요
예시 — 무게
수치: 1.12kg
AI 해석: 15인치 노트북 중 최경량 수준. 매일 들고다니기 좋아요
예시 — 저장공간
수치: 256GB SSD
AI 해석: 기본 사무엔 충분하지만, 파일이 많다면 외장 드라이브 고려가 필요해요
※ 사용자 용도를 모르는 경우 일반적 해석을 제공. 프로토타입에서는 스펙 수치 옆 AI 배지로 DB 수치와 해석을 시각 구분
가격 로직 — 에누리만 줄 수 있는 것
정보설명
현재 최저가 배송비 포함 실구매가 기준 · 최저 쇼핑몰 1~3개 표시
출시가 대비 할인율 출시 이후 얼마나 내렸는지 직관적으로 제공 (에누리 PDP 기존 데이터 활용)
3개월 평균 대비 ★ 에누리 가격 추이 DB 기반 · 판정의 핵심 근거. 에누리만 제공 가능한 고유 정보
최저가 알림 연결 "기다려봐요" 판정 시 목표가 알림 설정으로 자연 연결 → 재방문 유도 장치
※ AI는 미래 가격 예측("앞으로 내릴 것 같아요")을 하지 않습니다. 데이터 기반 현재 상태만 표현합니다.
리뷰 활용 — 기존 AI 리뷰 요약 데이터 활용
AI 에이전트가 리뷰를 직접 요약하지 않는다
에누리는 이미 상품별로 리뷰 데이터를 기반으로 AI 리뷰 요약을 생성·제공하고 있다. AI 에이전트는 이 기존 요약 데이터를 그대로 가져와 노출하는 방식으로 활용한다. 별도의 리뷰 재요약·재생성 작업은 불필요하다.
리뷰의 역할
스펙으로 확인 불가한 실사용 만족도 전달. 판정·스펙 다음 "실제로 어떤가"를 보완하는 참고 정보
적용 조건
AI 리뷰 요약이 존재하는 상품에만 노출
요약 데이터 없는 상품 → 리뷰 카드 미노출
에누리 AI 리뷰 요약 + 키워드 태그 그대로 표시
AI 에이전트 노출 예시 (에누리 AI 리뷰 요약 데이터 활용)
사양도 좋고 가볍게 들고다니기 딱이에요! 키보드 편하고 배터리도 오래 가서 대학생이나 직장인에게 완전 추천. 문서 작업도 영상 편집도 쾌적하네요.
※ AI 에이전트가 리뷰를 추가 수집·요약하는 구조가 아니므로, 리뷰 데이터의 정확성과 최신성은 에누리 AI 리뷰 요약 파이프라인에 의존합니다.
추가 질문 칩 — 상황 반응형
모든 상품에 같은 칩 고정 → 사용자가 무시함. 판정 결과·리뷰 단점 언급 여부에 따라 다른 칩을 노출한다.
상황제공되는 칩 예시
"지금 사도 좋아요"
발열이 심하지는 않나요? 비슷한 사양 중 더 저렴한 게 있나요? 더 내리면 알려주세요
"조금 기다려봐요"
가격 내리면 알림 받고 싶어요 역대 최저가는 언제였나요? 비슷한 다른 노트북도 있나요?
리뷰 단점 언급 시
저장공간 부족하다는 후기가 많나요? 저장공간 더 넉넉한 모델 있나요?
항상 포함 (1개)
비슷한 다른 노트북도 있나요?
→ 에누리 검색결과 페이지 연결
※ "다른 노트북 추천해줘" 요청 시: 이 에이전트는 현재 상품 데이터만 보유하므로 직접 추천 불가. 에누리 검색결과 페이지로 연결 안내
사용성 방향 — 프로토타입 비교
공통: 버튼 클릭 → 로딩(~1.3초) → 판정 자동 표시  |  A안: 이후 스펙·가격·리뷰 카드 자동 전개  |  B안: 이후 1차 질문 칩 제공 → 답변 인라인 표시 → 2차 질문 칩
A안 — 자동 전개형
  • 판정 + 스펙·가격·리뷰 카드가 모두 펼쳐진 상태로 표시
  • 각 카드는 접기 가능 (아코디언)
  • 진입 즉시 핵심 정보 전달
  • 스크롤 한 번으로 전체 파악 가능
⚠ 초기 정보량이 많아 스크롤 부담 가능
⚠ 대화형 에이전트보다는 정보 주입 에이전트 역할이 더 강함
B안 — 대화형
  • 판정만 자동 표시. 나머지 정보는 질문 칩으로 꺼냄
  • 1차 칩: "이 스펙이 내 용도에 맞을까요?" 등 구어체 질문으로 제공
  • 칩 선택 시 해당 답변 인라인 표시 → 맥락에 맞는 2차 질문 칩 등장
  • 사용자가 대화를 주도하는 구조
⚠ 칩을 선택하지 않으면 판정 외 정보 미노출
A안은 정보를 한 번에 제공해 빠른 파악이 가능하고, B안은 판정 후 사용자가 궁금한 것만 대화로 꺼내는 구조.
판정·최저가 알림 설정은 두 안 공통 제공.
💬 추가 고민 필요
B안은 에이전트가 먼저 질문 칩을 제시하고 사용자가 선택하는 구조로, 대화의 주도권이 에이전트에 있음. 진정한 대화형으로 발전하려면 사용자가 자유롭게 입력한 질문에 AI가 얼마나 정확하고 유연하게 대응할 수 있는가가 관건. 예: "이거 대학원생이 써도 될까요?", "배터리 하루 종일 버텨요?" 같은 예측 불가한 질문에 에누리 데이터 기반으로 답할 수 있는 LLM 응답 품질과 범위 설계가 선행되어야 함.
설계 원칙
01
두괄식으로 답한다
핵심 결론(판정·요점)을 먼저 전달하고, 이를 뒷받침하는 근거(스펙 해석·가격 데이터·리뷰 요약)를 이어서 제공한다. 줄글 나열 방식 금지
02
추천 이유 없이 추천하지 않는다
모든 판정과 스펙 해석에 근거(DB 기반 수치 또는 리뷰 요약)를 명시
03
가격은 AI가 생성하지 않는다
에누리 가격비교 DB에서 실시간 참조. 데이터 없으면 "확인 필요"로 안내
04
스펙은 해석만, 나열 금지
수치 나열은 스펙 탭과 중복. AI는 용도 언어로 번역만 담당
05
리뷰는 기존 AI 요약 데이터를 그대로 활용한다
에누리가 이미 생성한 AI 리뷰 요약 데이터를 가져와 노출. 에이전트가 별도로 리뷰를 재수집·재요약하지 않는다. 요약 데이터가 없는 상품은 리뷰 카드 미노출
06
모르면 모른다고 한다
리뷰 미보유 상품 → 리뷰 카드 미노출. 다른 상품 추천 요청 → 불가 안내 + 검색 연결
07
길면 이탈한다
판정 1장 + 카드 3개(스펙·가격·리뷰) + 질문 칩. 이 구조를 초과하지 않는다
